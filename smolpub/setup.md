# Smol Pub Setup Guide

Smol Pub provides several customization options for your Gemini blog.

## Navigation Links

Default navigation structure:
* [Posts](https://smol.pub/)
* [Home](https://smol.pub/home)
* [Pages](https://smol.pub/pages)
* [Files](https://smol.pub/files)
* [Settings](https://smol.pub/settings)
* [Visit blog ↗](http://brennan.smol.pub/)

## Layout Customization

### Post List Layout (/posts)
- **Header**: [https://smol.pub/header](https://smol.pub/header)
- **Footer**: [https://smol.pub/footer](https://smol.pub/footer)

### Single Post Layout
- **Header**: [https://smol.pub/post-header](https://smol.pub/post-header)
- **Footer**: [https://smol.pub/post-footer](https://smol.pub/post-footer)

## Theme (CSS)

### Public Theme
- **URL**: [https://smol.pub/theme](https://smol.pub/theme)
- Controls the public-facing appearance of your blog

### Admin Theme
- **URL**: [https://smol.pub/uitheme](https://smol.pub/uitheme)
- Controls the admin interface appearance

## Notes

- Headers and footers use Gemtext format
- CSS themes use standard CSS syntax
- Customizations are applied through the Smol Pub interface
- Your blog will be accessible at: `http://brennan.smol.pub/`
