The Shell

Everything starts at the shell. ssh you@tty.sdf.org loads multi-user NetBSD with bash, ksh, tcsh, rc, and zsh; editors from ed to emacs; and "hundreds of shell/network utilities" per the join page. Plus ping, traceroute, dig, whois, and finger.

Email

  • Your address is you@sdf.org, delivered to your home directory. Read it with mutt, alpine, elm, or mailx
  • Webmail: mx.sdf.org (SDF credentials)
  • Mail clients: IMAP mx.sdf.org:993, SMTP mx.sdf.org:465 (SSL)
  • Forwarding: put a destination in ~/.forward

Web space

  1. Run mkhomepg on the shell and it creates ~/html and asks which URL you want
  2. Drop files in ~/html and the site is live immediately at you.sdf.org
  3. ARPA members can pick a vanity domain from ~60 choices (pdp10.org, twenex.org, chaosnet.org, freak.net, multics.org…). See wiki.sdf.org for the list

CGI works out of the box. Shell/awk/sed for everyone, and full php/perl/python/ruby for ARPA members. Details here.

Gopher + Gemini

Run mkgopher, choose setup, then quit, it creates ~/gopher (a symlink into /ftp/pub/users/you) served as both gopher://sdf.org/1/users/you and gemini://sdf.org/users/you. One directory, two protocols. Write a gophermap or add .gmi files. Permissions matter: files group-readable (chmod g+r), directories g+rx. SDF's own guides: gopher setup and gemini setup.

Community: com, bboard, USENET

  • com: the real-time chat. Type w to see who's on. It predates IRC
  • bboard: the message board: announcements, tech questions, decades of archives. Ask for help here
  • USENET: read/post with slrn, tin, nn, or alpine's news mode; ARPA adds the ClariNET feed
  • finger: set ~/.plan and ~/.project for finger you@sdf.org

ARPA ($36, lifetime)

  • Outbound tools: telnet, ssh, sftp, ftp, snarf, wget, ytalk, external IRC. Free accounts are inbound-only; ARPA opens the network both ways
  • File transfer: scp/sftp and non-interactive SSH: ssh-copy-id is enabled (transferring files guide)
  • Development: gcc, perl, php, python, ruby, elisp on the box
  • Full CGI: php/perl/python/ruby on your site
  • VoIP: internet calling, voicemail, conferencing (PSTN calling is a $15/quarter add-on with a real DID option)
  • ttytter: command-line Twitter/X client
  • UUCP + ClariNET: mail and newsfeeds via TCP or dialup
  • Voting rights: on system features and policy
  • Quotas: ~150 MB / 5000 files each for home, mail, webspace, gopherspace

Paid add-ons stack on top: DBA ($30/yr, MySQL+sqlite), VHOST ($5–20/mo: host your own domain with automatic Let's Encrypt SSL and private logs), DNS ($20/yr), VPM virtual mail ($20/yr), MLIST majordomo lists ($30/yr), REGIS domain registration ($18/yr), and PSTN VoIP ($15/qtr). Enable them through maint.

MetaARPA ($11/quarter)

The MetaArray (800 GB quota compute cluster: run metaarray on the SDF shell to enable, then ssh ma.sdf.org), cron, screen/tmux, background processes with TCP port allocation, SSH tunneling, rsync, java, SBCL, SSL on your site, mdns.org dynamic DNS, NextCloud, and the ability to validate new users yourself. There's also a VPN membership ($4/mo) and full VPS slices ($7–28/mo: your choice of CentOS, Debian, Ubuntu, OpenSUSE, Trisquel, Fedora, Slackware, NetBSD, FreeBSD, OpenBSD, DragonFly, OmniOS, Solaris, or Plan 9).

Get Started

  1. ssh new@sdf.org (or ssh.sdf.org in a browser) and create your account
  2. Run maint to see your level; get validated ($1 or ask a MetaARPA member)
  3. mkhomepg for web space, mkgopher for gopher+gemini, com to meet people, bboard to ask questions
  4. Upgrade to ARPA. It's only $36.
